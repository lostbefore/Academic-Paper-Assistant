## 1.1 项目背景

2023 年以来，生成式大语言模型快速进入高校写作场景。围绕「AI 能不能写论文」的讨论已经很多，但真正影响教学与科研秩序的是另外三个更具体的问题：

1. **不可核查**：模型可以流畅地生成并不存在的文献、作者、期刊与数据，读者无法判断一句话是否有来源；
2. **不可复现**：同一段提示词在不同时间得到的结构与引用完全不同，无法作为教学过程被记录与评价；
3. **不可追溯**：学生或研究者使用了 AI，但缺乏使用过程留痕，机构无从开展学术诚信教育。

因此本项目不把「一键生成一篇论文」当作目标，而是尝试把论文写作拆成**可观察、可编辑、可核查**的若干阶段，让 AI 参与其中但每一步都留下证据。这构成了本系统全部功能设计的出发点。

## 1.2 目标用户

| 用户类型 | 典型场景 | 核心诉求 |
|---|---|---|
| 本科生 | 课程论文、毕业论文初稿 | 不知道如何搭建结构，需要示范性框架 |
| 研究生 | 文献综述、开题报告 | 需要快速掌握某方向的研究脉络与代表文献 |
| 青年教师 | 跨学科写作、项目申报书 | 需要把不熟悉的领域快速结构化 |
| 教学管理者 | 学术写作课程 | 需要可展示、可复现的写作流程示例 |

系统定位为**写作辅助工具**，不替代作者的研究设计、数据获取与最终判断。

## 1.3 现状与问题分析

对同类工具的实际使用观察，归纳出五个具体痛点：

| 编号 | 痛点 | 具体表现 | 本系统的应对 |
|---|---|---|---|
| P1 | 引用凭空捏造 | 生成的参考文献查无此文 | 参考文献只来自实时检索结果，正文引用编号与文献表严格对应 |
| P2 | 结构千篇一律 | 无论什么题目都是「引言—现状—问题—对策」 | 先由模型生成提纲，再逐节写作，提纲可核对 |
| P3 | 过程黑箱 | 点一下按钮，几秒后出一大段文字 | 六阶段流水线 + SSE 实时事件流 + 事件日志落库 |
| P4 | 无法修改 | 只能整篇重新生成，改一处要重来 | 章节级编辑与章节级重写，其余章节作为上下文 |
| P5 | 无法交付 | 复制粘贴到 Word 后格式全乱 | 服务端生成 DOCX/PDF，含中文排版与参考文献表 |

## 1.5 非功能需求

| 类别 | 指标 | 实现方式 |
|---|---|---|
| 性能 | 单篇 2000–3000 字论文 ≤ 60 秒 | 分节并发生成受控，单节一次调用 |
| 性能 | 文献检索 ≤ 5 秒 | 三源并发 + 超时隔离 + 缓存 |
| 可靠性 | 单源失败不影响整体 | 每源独立 try/except，失败记为 warning |
| 可靠性 | 进程重启不留下「假运行」状态 | 启动时扫描 queued/running 并标记失败 |
| 安全 | 密码不可逆存储 | bcrypt（cost=12） |
| 安全 | 越权访问拦截 | 每个论文接口校验 `user_id` |
| 安全 | 密钥不落库、不回显 | 仅从环境变量读取，`/api/status` 只返回布尔值 |
| 可维护 | 分层清晰 | router / service / db 三层，单文件职责单一 |
| 可移植 | 单进程即可运行 | 前端构建产物由后端同端口托管 |
| 合规 | 不生成虚构数据 | 提示词硬约束 + 无检索结果时不标注引用 |

## 1.6 范围与边界

**包含**：论文结构设计、文献检索、初稿生成、章节编辑、格式化导出、账户与权限。

**不包含**（明确的设计选择）：

1. 不提供「代写并直接提交」的闭环——系统没有一键投稿、没有绕过作者确认的发布通道；
2. 不生成实验数据、问卷数据或统计显著性结果——正文只能对研究设计作推演式描述；
3. 不做查重、不做 AI 内容检测——这类能力应由第三方权威系统提供；
4. 不做多人协作与版本分支——当前定位为个人写作工作台。

## 1.7 验收标准

| 编号 | 验收项 | 判定方式 |
|---|---|---|
| AC-01 | 新用户可注册、登录并进入工作台 | 手工 + 自动化用例 |
| AC-02 | 提交选题后 60 秒内产出完整六节论文 | 实测（见文档 08） |
| AC-03 | 参考文献全部可在 OpenAlex/Crossref/arXiv 检索到 | 人工抽查 DOI |
| AC-04 | 引用的编号在文献表中存在 | 抽检正文 `[n]` 与文献表 |
| AC-05 | DOCX/PDF 中文不乱码、段落有缩进 | 打开导出文件核对 |
| AC-06 | 刷新页面后生成进度不丢失 | 重新进入论文页核对 |
| AC-07 | 他人无法访问我的论文 | 自动化用例 `test_other_users_cannot_read_someone_elses_paper` |
| AC-08 | 服务异常重启后论文状态不为 running | 启动自检逻辑 + 用例 |
