## 4.1 通用约定

| 项目 | 约定 |
|---|---|
| 基础路径 | `/api` |
| 数据格式 | `application/json; charset=utf-8` |
| 认证 | `Authorization: Bearer <JWT>`，除注册、登录、健康检查外全部必需 |
| 时间格式 | UTC ISO-8601，如 `2026-11-16T06:34:57Z` |
| 错误格式 | `{"detail": "人类可读信息"}`，参数校验错误为 FastAPI 标准数组 |
| 状态码 | 200 成功 / 201 创建 / 202 已受理 / 204 删除 / 400 参数 / 401 未认证 / 403 越权 / 404 不存在 / 409 状态冲突 / 422 校验失败 / 429 限额 / 500 服务端错误 / 502 模型错误 / 503 未配置 |

分页：论文列表使用 `limit`（1–500，默认 100），按 `created_at DESC` 排序；数据量级不需要游标分页。

## 4.3 关键接口详述

### 4.3.1 POST /api/papers

请求：

```json
{
  "title": "大语言模型辅助学术写作的可靠性评估",
  "field": "教育技术学",
  "keywords": ["大语言模型", "学术写作", "学术诚信"],
  "length": "short",
  "citation_style": "gbt7714",
  "language": "zh",
  "target_words": 2800,
  "reference_count": 8,
  "instructions": "采用混合研究方法"
}
```

约束：`title` 4–300 字；`keywords` ≤ 12 个；`target_words` 800–12000；`reference_count` 4–40；
`language ∈ {en, zh}`；`citation_style ∈ {apa, mla, ieee, gbt7714}`。

响应 `202`：

```json
{
  "id": "p_518f73961884",
  "title": "大语言模型辅助学术写作的可靠性评估",
  "status": "queued",
  "stage": "queued",
  "progress": 0,
  "sections": {},
  "request": { "...": "参数快照" }
}
```

错误：

| 场景 | 状态码 | detail |
|---|---|---|
| 服务端未配置模型 | 503 | The language model is not configured on this server… |
| 超出论文数量上限 | 429 | Paper limit reached for this account |

### 4.3.2 GET /api/papers/{id}/events（SSE）

请求头：`Authorization: Bearer <token>`（也支持 `?token=` 作为兜底）。

响应 `text/event-stream`，帧格式：

```
id: 12
event: progress
data: {"id":12,"ts":"2026-11-16T06:23:41Z","stage":"writing","level":"info",
       "message":"Finished 文献综述 (677 words)","data":{"section":"literature_review"}}

event: done
data: {"status":"completed"}
```

协议要点：

- 每 0.5 秒轮询一次 `events` 表，只取 `id > last_id` 的记录，天然支持断点续传；
- 空闲时每 10 秒发送注释帧 `: ping` 保活；
- 客户端断开通过 `request.is_disconnected()` 感知并结束生成器；
- 终态（`completed/failed/cancelled`）且无新事件时发送 `done` 并关闭。

前端不使用 `EventSource`，而是用 `fetch` + `ReadableStream` 手动解析，以便携带 Bearer 头。

### 4.3.3 POST /api/papers/{id}/sections/{key}/regenerate

```json
{ "instructions": "更突出方法局限，减少描述性内容" }
```

响应：

```json
{ "section": "conclusion", "content": "……", "paper": { "...完整论文对象" } }
```

约束：论文必须处于终态；`key` 必须在提纲中存在，否则返回 400。

### 4.3.4 GET /api/papers/{id}/export/{fmt}

| fmt | Content-Type | 说明 |
|---|---|---|
| docx | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | 宋体/黑体、首行缩进、悬挂缩进 |
| pdf | `application/pdf` | A4，中文字体 |
| md | `text/markdown; charset=utf-8` | 便于二次编辑 |
| bib | `application/x-bibtex` | 文献管理软件导入 |

仅 `completed` 状态可导出，否则 `409`。文件名取论文标题（非法字符替换为下划线，截断 60 字符）。

## 4.4 认证流程

```
POST /api/auth/register  ──► 201 {access_token, user}
POST /api/auth/login     ──► 200 {access_token, user}
GET  /api/auth/me        ──► 200 user
```

- token 载荷：`sub`(用户 id)、`email`、`role`、`iat`、`exp`、`jti`；
- 有效期由 `TOKEN_TTL_HOURS` 控制（默认 336 小时 = 14 天）；
- 前端把 token 存 `localStorage`，axios 拦截器自动附加；收到 401 时清空并跳转登录页；
- 服务端校验签名与过期时间，用户被删除后 token 立即失效（每次请求回查用户）。

## 4.5 错误处理示例

```json
// 401
{"detail": "Not authenticated"}

// 403
{"detail": "You do not have access to this paper"}

// 409
{"detail": "Paper is already finished"}

// 422（FastAPI 校验）
{"detail":[{"type":"string_too_short","loc":["body","title"],"msg":"String should have at least 4 characters"}]}
```
