## 二、材料形成方式说明

为保证材料可核查，本套文档按以下方式形成，不含虚构的实验数据、会议记录或用户调研：

1. **结构类内容**（架构、表结构、接口、提示词）直接取自当前仓库源码，路径与函数名可逐一对照；
2. **数据类内容**（代码行数、接口数量、数据库对象、提交记录）由脚本从仓库与运行库自动导出，脚本本身也在仓库中（`docs/build_appendix.py`）；
3. **测试类内容**为实际执行 `pytest` 的输出，原始日志见附录 E，任何一条用例都可以在本地复跑；
4. **截图**取自实际运行的系统实例（本地开发实例与线上部署实例），页面数据为真实生成结果；
5. **时间信息**以 git 提交记录为准：初版提交于 2026-03-20，v2.0 重构与本文档集编制于 2026-11-16。

> 如果提交材料需要按特定周期归档，请以项目负责人的实际工作记录为准；本文档集不对未留存的过程活动作推测性描述。

## 三、系统一览

| 项目 | 内容 |
|---|---|
| 名称 | 学术论文助手 Academic Paper Assistant |
| 版本 | v2.0.0 |
| 形态 | B/S 架构，自托管 Web 系统 |
| 后端 | Python 3.10+ / FastAPI / SQLite(WAL) |
| 前端 | React 18 / TypeScript / Vite / Tailwind CSS |
| 模型 | 任意 OpenAI 兼容接口（默认 DeepSeek `deepseek-chat`） |
| 文献源 | OpenAlex、Crossref、arXiv（可选 Semantic Scholar） |
| 导出 | DOCX、PDF、Markdown、BibTeX |
| 代码规模 | v2 主体约 8,100 行（backend 3,728 + frontend 3,017 + 其他约 1,400），另有 v1 归档 8,309 行 |

python start.py                 # 启动后访问 http://127.0.0.1:8000
cd backend && pytest -v         # 37 条自动化测试
