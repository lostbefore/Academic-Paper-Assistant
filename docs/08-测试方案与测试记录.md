## 8.1 测试策略

采用分层策略，越靠下越自动、越靠上越依赖人工核对：

| 层次 | 范围 | 方式 | 数量 |
|---|---|---|---|
| 单元测试 | 引用格式、流水线辅助函数、密码与令牌、文献合并 | pytest，无网络 | 23 |
| 接口测试 | 认证、权限、CRUD、导出、状态码 | FastAPI TestClient + 临时数据库 | 8 |
| 组件/模块测试 | 导出件结构（zip/pdf 签名）、SQLite 缓存 | pytest + 临时目录 | 6 |
| 端到端验收 | 真实模型生成、SSE、页面操作 | 手工 + 浏览器截图 | 8 个验收项 |
| 部署验证 | 线上实例登录、生成、导出 | 手工 + HTTP 探测 | 见文档 09 |

原则：

- **测试不依赖外网**：文献源与模型在单元测试中全部打桩（monkeypatch），保证离线可复跑；
- **测试不污染正式数据**：`conftest.py` 在导入应用前把 `DATA_DIR` 指向临时目录；
- **失败必须能定位**：每条用例只验证一个行为，断言信息包含预期与实际。

## 8.5 缺陷记录

以下缺陷均在本项目开发过程中实际出现并被修复，修复后由自动化用例或部署验证确认。

### BUG-01 创建论文返回 500：no running event loop

| 项 | 内容 |
|---|---|
| 现象 | `POST /api/papers` 返回 `{"detail":"Internal server error"}`，日志为 `RuntimeError: no running event loop` |
| 定位 | 路由函数 `create_paper` 写成了同步 `def`，FastAPI 将其放入线程池执行，线程内没有事件循环，`asyncio.create_task` 失败 |
| 修复 | 改为 `async def create_paper` / `async def retry_paper` |
| 验证 | 创建返回 202，SSE 能持续收到事件 |

### BUG-02 英文作者姓名解析颠倒

| 项 | 内容 |
|---|---|
| 现象 | APA 输出 `Ashish, V.`，IEEE 输出 `V. Ashish` |
| 定位 | `_split_name` 把 `parts[:-1]` 当作姓氏，实际应取最后一段 |
| 修复 | 取 `parts[-1]` 为姓氏，并支持 `Family, Given` 逗号形式 |
| 验证 | 6 条引用用例全部通过 |

### BUG-03 线上服务反复重启：.env 权限不足

| 项 | 内容 |
|---|---|
| 现象 | `apa.service` 状态 `activating (auto-restart)`，日志 `PermissionError: [Errno 13] Permission denied: '/opt/academic-paper-assistant/.env'` |
| 定位 | 安装脚本执行 `chmod 600 .env`，但文件属主仍是 root，服务以 `apa` 用户运行 |
| 修复 | 先 `chown apa:apa .env` 再 `chmod 600` |
| 验证 | 服务 `active (running)`，`/api/health` 返回 ok |

### BUG-04 中文论文长度严重超标

| 项 | 内容 |
|---|---|
| 现象 | 目标 2500 字，实际产出 4971 字（1.9 倍） |
| 定位 | 两个原因叠加：① `max_tokens = words * 2.2` 按英文习惯估算，中文实际约 5.5 字符/token；② 提示词写「about 800 words」，模型按英文词理解；③ 模型照抄示例中的字数未重标定 |
| 修复 | 分语言 token 预算（中文 `0.55/字`）、提示词给出汉字区间、提纲字数按目标重标定 |
| 验证 | 目标 2800 字产出约 3400 字（1.21 倍），目标 2200 字产出 2686 字（1.22 倍） |

### BUG-05 前端 `npm run build` 失败

| 项 | 内容 |
|---|---|
| 现象 | `tsc` 报 3 类错误：`ThemeContext` 中 React 未使用、`Paper` 上不存在 `citation_style`、`import.meta.env` 无类型 |
| 修复 | 删除未使用的导入；改用 `paper.request?.citation_style`；新增 `vite-env.d.ts` 声明 |
| 验证 | `tsc && vite build` 通过，产物 440 KB（gzip 139 KB） |

### BUG-06 测试期望值错误

| 项 | 内容 |
|---|---|
| 现象 | `test_word_count_counts_cjk_characters_and_latin_words` 期望 6 实际 5 |
| 定位 | `AI` 在按词统计时是 1 个 token，测试写成了 2 |
| 修复 | 修正测试期望值（1 + 2 + 2 = 5） |
| 说明 | 这是测试自身的错误，记录在此以说明缺陷定位过程 |

## 8.8 未覆盖与后续计划

1. **真实模型调用的自动化**：会消耗 token 且结果非确定，当前仅做手工端到端；后续可引入录制回放（VCR）固定响应；
2. **浏览器端自动化**：截图与交互为人工执行，尚未接入 Playwright；
3. **并发压力测试**：单机 2 并发是保守配置，未做 10 并发以上的压测；
4. **PDF 字体兼容**：CID 字体依赖阅读器，个别老旧阅读器可能提示字体缺失，后续可改为内嵌 Noto CJK 子集。
